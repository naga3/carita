# Visuddhimagga 第3章の確認

確認日: 2026-09-08。三蔵外の論書として commentarial に分類。

## 使用した版

- [パーリ本文掲載版](https://vietheravada.net/kinhdien/visuddhimagga/visuddhimagga1.htm): Cariyāvaṇṇanā §43–46、Cattālīsakammaṭṭhānavaṇṇanā §47。一次文献本文を確認。
- [Ñāṇamoli 英訳 第3章](https://edhamma.github.io/vism/sphinx/build/html/ch-03.html): 節番号と読解の照合に使用。長文を転載せず、日本語はパーリ本文に対応する自作要約。
- `III.88` 等は英訳の段落番号。パーリ掲載版の大きな節番号と同一でないため、両方を Source.location に記録する。パーリ版は章内アンカーがないため、外部URLを開いて位置の語句を検索する。

## 文献確認の結果

- III.74–78 / §43: rāga, dosa, moha, saddhā, buddhi, vitakka の六気質。混合を認める。貪と信、瞋と智、痴と尋の類似を記す。
- III.87 / §45: 姿勢・動作・食事・対象を見ることなど・起こる心の状態の五カテゴリー。
- III.88–90: 歩行や立つ/座る/寝る動作。III.90 は信・智・尋の動作に、それぞれ対応する類似を適用する。
- III.91–92: 掃除やその他の作業。類似の三組を明記。
- III.93: 食べ方・嗜好。同様に類似を適用。
- III.94: 視覚などの対象への評価。同様に類似を適用。
- III.95: 六気質それぞれについて頻出する心の状態を列挙。
- III.96: 観察法すべてが本文・注釈に伝えられたわけではないという著者自身の留保。動作の変更や混合による判別の限界を説明。質問と結果に必ず表示。
- III.105 / §47: 四十業処の列挙。六随念の具体名の照合にも使用。
- III.121–122 / §47: 気質ごとの適性。ただし排他的な割当ではない。

旧版はwalking/work/eating/seeingと各気質の自己評価6問。現行のq01–q10は新しいIDを持ち、保存版も2へ更新して旧回答の読み替えを防ぐ。

## 修行法と Mahāniddesa との差

| 気質 | 清浄道論 III.121                                | Mahāniddesa                        |
| ---- | ----------------------------------------------- | ---------------------------------- |
| 貪   | 十不浄・身至念                                  | 不浄についての教え                 |
| 瞋   | 四梵住・四色遍                                  | 慈の修習                           |
| 痴   | 入出息念                                        | 学習・質問・聞法・対話・師との生活 |
| 尋   | 入出息念                                        | 入出息念                           |
| 信   | 仏・法・僧・戒・捨・天の六随念（名称はIII.105） | 信を起こす仏の覚り等の対象         |
| 智   | 死念・寂止随念・四界分別・食厭想                | 無常・苦・無我の観                 |

III.121 の他の遍・無色の全気質への適性や遍の大きさは調査範囲には含むが、MVPでは個別推薦データとして網羅しない。III.122 の非排他性を表示して、推薦以外が無効であるとの誤解を避ける。

## 除外

過去生・体液・身体要素からの因果判定（本文自身も一部の説を批判）、寝姿・衣の着方、採用した甘味/酸味を超える食の嗜好の追加質問、住居/食事環境の処方、不浄の詳細手順、未検証の語義拡張、現代心理学との対応を除外。質問数のために補完しない。
