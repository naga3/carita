# 一致数（質問票 v2）

点数は仏典由来ではなく、回答と記述の関係を整理する実装上の便宜。すべて strength = 1。一つの質問の一つの気質への対応を1件として数える。重み付きの確率や相性は算出しない。

- 質問IDごとに一つの回答。変更は置換し、履歴を合算しない。
- 未知の質問/回答IDを排除。direct / modernized のみ集計し、interpretive は実行時にも排除する。
- 同じ回答中の同一気質への重複証拠は1件。
- 最大値 > 0 のすべてを首位として表示。全ゼロなら首位なし。
- 修行法は1件以上一致した全気質について表示。全ゼロなら割り当てない。
- 全10問回答を結果表示の条件とする。最後の選択肢は有効回答だが加点なし。
- 加点なしの回答を、反対の気質への証拠にはしない。

q02とq06は同じ節の別の特徴を扱う。この2問を統計的に独立した測定とみなさない。最大件数を同数にしても心理測定上の公平性・妥当性の証明にはならない。

## 文面・並びの変更

抽象的な自己評価や気質名を連想させる問いを、原典の特徴を直接尋ねる場面へ置換。選択肢の配列は問ごとに異なる固定順とし、同じ位置＝同じ気質という並びを避ける。ランダム値は使用せず、再読込・戻る操作でも並びを維持する。

日常行動から歩行・内面・別の行動を推測するモデルは導入しない。対人場面からの足の上げ下げ推定に文献上の裏付けがないため、旧walkingは不採用。

推測されにくさや回答バイアス低減は未検証。今後はユーザーに問いの意味を説明してもらう等の理解度確認で、語義を保てているか評価する。

## 保存回答の版

`QUESTIONNAIRE_VERSION = 2`。保存キーは互換性のため `carita:answers:v1` のまま、内容の `version` を2とする。旧版の内容は新問に読み替えず、改訂通知と再回答の導線を表示する。旧保存値は新しい回答の保存、または消去操作までそのまま残る。新回答の保存時に版2の内容に置換する。
