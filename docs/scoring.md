# 一致数

点数は仏典由来ではなく、回答と記述の関係を整理する実装上の便宜である。現在すべて strength = 1。実装は strength を重みとして掛けず、一つの質問の一つの気質への対応を1件として数える。将来2を導入する場合も「一致件数」を重み付きスコアに黙って変更しない。

- 質問IDごとに一つの回答。変更は置換し、履歴を合算しない。
- 未知の質問/回答IDを排除する。direct / modernized のみ集計し、interpretive は実行時にも排除する。
- 同一回答中の同一気質への重複証拠は1件。
- 上位は最大値 > 0 のすべて。全ゼロは首位なし。割合や信頼度は算出しない。
- 修行法は1件以上一致した全気質について表示。全ゼロなら割り当てない。
- 全10問回答を結果画面の条件とする。判断不能という回答は有効な回答で、加点なし。

## 加点機会

| 質問                                                  | 対応                                                                  |
| ----------------------------------------------------- | --------------------------------------------------------------------- |
| walking / work / eating / seeing                      | 各々、貪・信 / 瞋・智 / 痴・尋のいずれかの組に1件ずつ、または加点なし |
| mental-raga / dosa / moha / saddha / buddhi / vitakka | 各気質に1問ずつ、よくあるなら1件、その他0件                           |

各気質に最大5件。二気質への対応は III.90,92–94 が述べる類似に基づき、一方にだけ帰属させない。1回答に2件つく場合があるため合計は回答数を超え得る。

原典の観察記述からの自己回答化、観察項目の抜粋、単純加算は本アプリの設計である。測定尺度の妥当性・独立性・予測性能は検証していない。加点機会の同数化は心理測定上の公平性の証明ではない。
