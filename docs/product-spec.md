# Carita MVP

目的は人格分類ではなく「どの記述との一致か」を追跡できること。日本語・モバイル優先。

| ルート        | 内容                                                                      |
| ------------- | ------------------------------------------------------------------------- |
| `/`           | 趣旨、10問への導線、六気質、文献への導線                                  |
| `/questions/` | 1問ずつ、戻る/次へ、回答保持、質問の現代化・出典開示                      |
| `/result/`    | 概要 → 件数 → 修行法 → 三蔵根拠 → 論書補足 → 一致理由 → 全回答 → 注意事項 |
| `/sources/`   | 文献階層、採用箇所、パーリ原文・要約、外部参照                            |
| `/about/`     | 原典方針、解釈水準、一致数、限界、プライバシー                            |

10問すべて modernized。4つの観察カテゴリーと六気質それぞれの頻出する心の状態を採用。判断不能の選択肢を常に用意。

UI: 紙に近い白、深緑、控えめな罫線、システム日本語フォントとパーリ語のセリフ体。画像や外部フォントの依存はない。ラジオ入力・fieldset・進捗・キーボードフォーカス・本文スキップ・reduced motion に対応。

除外: アカウント、DB、API、LLM、解析、心理学類型への対応、割合、人格断定、未確認の原典対応、実践の詳細な指導手順。
