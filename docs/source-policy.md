# 出典方針

- 実装前にパーリ本文を確認。確認日: 2026-09-08。
- canonical はパーリ三蔵の分類上の位置を示し、成立年代や仏陀の逐語的発言を保証しない。Mahāniddesa は三蔵内の解釈文献。
- Visuddhimagga は三蔵外の論書。質問はその第3章の記述に限定する。
- 自作の日本語要約を用いる。翻訳の長文転載は禁止。
- direct は文献との近さであり、科学的妥当性を意味しない。自己回答形式への置換は modernized とする。interpretive はスコア対象外。
- 原典の身体観察は現代的な質問票ではない。III.96 の留保を併記し、身体条件から人格を断定しない。
- 未確認の意味・現代心理学への対応・因果推定は追加しない。出典IDと箇所のないデータは禁止。
